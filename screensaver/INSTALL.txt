Launch Countdown for Windows 10 / 11 (64-bit)

Two ways to run the same program:
  LaunchCountdown.exe   the app: a normal window with every tab. It stays on
                        the tab you click; switch whenever you like. F11 for
                        full screen.
  LaunchCountdown.scr   the screensaver (install it as below).

A native screensaver: it fetches its own data and draws everything itself.
It is not a web page in a window.

Install
  1. Extract this whole folder somewhere permanent, for example
     Documents\LaunchCountdown  (all the files must stay together, and it
     must be a folder you can write to, so it can update itself).
  2. Right-click LaunchCountdown.scr and choose "Install".
     Windows opens Screen Saver Settings with it selected; the small monitor
     there shows a live preview.
  3. "Settings..." opens its own settings: theme, launch sites, which slides
     to show and for how long, the 3D layers, display-off time, launch wake-up.

Mouse
  Moving the mouse never exits the screensaver. It brings up the tab bar and
  buttons (Hold, Scrub, Set T-0, Reset, Slideshow, Settings); click a tab to
  stay on it. In the 3D view, drag to turn, wheel to zoom, double-click to
  let it drift again.

Keys
  Esc, Space    exit the screensaver (in the app: leave full screen / slideshow)
  H             hold / resume (T-0 moves later by the length of the hold)
  Shift+S       scrub
  T             enter a new T-0 (kept until the source publishes a new time)
  R             reset to the published T-0
  Left, Right   previous / next slide        1-9  jump to a slide
  P             pause the slideshow          + -  seconds per slide
  L             follow the next launch in the list
  C             theme                        E    terminal-count layout on/off
  I             live video on/off            V    3D view
  X             3D vertical scale            O D  cloud volume / radar volume
  A B N         aircraft / vessels / NOTAM and NOTMAR areas
  W             wind arrows and labels       G Y  telemetry / key
  M             cloud and wind fields for launch time or now
  U             upper-wind source: automatic, live balloon, radar profile,
                published sounding, model
  F1, K         show this list on screen

Notes
  - Needs nothing installed for the display itself (.NET Framework 4.8 and
    OpenGL are part of Windows). Live video uses the Microsoft Edge WebView2
    runtime, which Windows 11 and current Windows 10 include; without it the
    video panels show the range map instead.
  - From T-1 hour to T+15 minutes it switches to the terminal count: clock
    top centre, 3D corridor left, live video right, timeline under the video.
  - Launch wake-up (on by default): a small helper in the notification area
    starts when you sign in, wakes the PC and display ten minutes before a
    launch at your selected sites and keeps them on until T+15 minutes.
    Waking from sleep needs "Allow wake timers" in the Windows power plan.
  - The display still sleeps otherwise: outside the launch window it makes no
    power requests, the Windows display timer applies as usual, and its own
    timer (default 30 minutes) switches the monitor off too.
  - Upper winds use measurements when T-0 is within six hours: balloons
    tracked live by SondeHub as they climb, the newest published sounding
    (Cape Canaveral, Vandenberg, Brownsville...) and the nearest NEXRAD's
    radar wind profile, with the forecast model filling the gaps.
    The KSC TDRWP profiler has no public live feed.
  - A helicopter with a JOLLY callsign is drawn green and never raises an
    area alert: the rescue helicopters are allowed inside.
  - Aircraft are shown only within 30 miles of the launch NOTAM airspace
    (Settings > 3D corridor changes the distance; 0 shows everything).
  - It updates itself: it checks the release every six hours and at start,
    and a newer build takes effect the next time it starts. The folder must
    be somewhere you can write to (not Program Files) for this to work.
    Settings > Display turns it off.
  - Vessels need a free aisstream.io key, entered under Settings > Sources.
  - Windows may warn that the file comes from an unknown publisher; it is
    not code-signed.

Remove
  Pick a different screensaver in Screen Saver Settings, then delete the folder.
  If the wake-up helper is running, untick it in Settings first (or exit it
  from its notification-area icon).
